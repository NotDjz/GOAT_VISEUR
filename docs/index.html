Démarrage avec Windows

Une case à cocher pose un raccourci dans le dossier Démarrage. Rien dans le registre : supprime le dossier, il ne reste aucune trace.

Raccourcis

Mod vaut Ctrl+Alt par défaut, et se change en Ctrl+Shift, Alt+Shift ou Ctrl+Alt+Shift si l'un d'eux entre en conflit avec ton jeu.

RaccourciAction
Mod + SOuvrir ou fermer les paramètres
Mod + HMasquer ou afficher le viseur
Mod + 1…0Changer de preset
Mod + QQuitter
